Introducción a la Unidad IV

En esta unidad estudiaremos los vectores o arrays unidimensionales, que son estructuras de datos fundamentales para almacenar colecciones de elementos del mismo tipo.

Un vector permite acceder a múltiples datos relacionados mediante un único nombre de variable y un índice numérico, facilitando el procesamiento de grandes volúmenes de información de forma ordenada.

¿Qué es un Vector?

Un vector (o array unidimensional) es una estructura de datos que almacena una colección de elementos del mismo tipo, accesibles mediante un índice.

Características principales:

  • Homogéneo: Todos los elementos tienen el mismo tipo de dato.
  • Indexado: Se accede a cada elemento mediante una posición (índice).
  • Contíguo en memoria: Los elementos se almacenan en posiciones consecutivas.
  • Tamaño fijo: El número de elementos se define al crear el vector.
  • Acceso rápido: El acceso a cualquier elemento es O(1) - tiempo constante.

Diferencia entre lista y vector:

Acceso Directo por índice Secuencial
Velocidad acceso Rápido O(1) Lento O(n)

Declaración e Inicialización de Vectores

Declaración de un vector:

La declaración especifica el tipo de dato y el tamaño del vector:

Var nombre_vector[tamaño] : tipo_dato

Ejemplos:
Var números[10] : Entero
Var calificaciones[5] : Real
Var nombres[20] : Cadena
Var flags[100] : Lógico

Inicialización de un vector:

La inicialización asigna valores a los elementos del vector:

// Inicialización individual
números[0] ← 12
números[1] ← 25
números[2] ← 8

// Inicialización con ciclo
Para i ← 0 Hasta 9 Hacer
    números[i] ← 0  // Inicializa todos en cero
FinPara

// Inicialización literal
Var días[7] : Cadena
días ← ["Lunes", "Martes", "Miércoles", "Jueves", "Viernes", "Sábado", "Domingo"]

Acceso a Elementos de un Vector

Para acceder a un elemento del vector, se utiliza el nombre del vector seguido del índice entre corchetes.

Sintaxis:

nombre_vector[índice]

Ejemplos de acceso:
Escribir números[0]        // Imprime el primer elemento
Escribir números[4]        // Imprime el quinto elemento
x ← números[3]             // Asigna el cuarto elemento a x
números[5] ← 99            // Asigna 99 al sexto elemento
Importante: En la mayoría de lenguajes, los índices comienzan en 0.
- Primer elemento: índice 0
- Segundo elemento: índice 1
- Elemento n: índice n-1

Ejemplo: Acceso con ciclo

// Leer 5 números y almacenarlos en un vector
Var números[5] : Entero
Para i ← 0 Hasta 4 Hacer
    Escribir "Ingrese el número ", i+1, ":"
    Leer números[i]
FinPara

// Mostrar los números leídos
Para i ← 0 Hasta 4 Hacer
    Escribir "Posición ", i, ": ", números[i]
FinPara

Recorrido de Vectores

Recorrer un vector significa acceder a cada uno de sus elementos de forma ordenada, generalmente usando un ciclo.
