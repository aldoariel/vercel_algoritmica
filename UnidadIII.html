Introducción a la Unidad III

En esta unidad estudiaremos las estructuras básicas de un algoritmo, que son los componentes fundamentales de cualquier programa. Un programa es un conjunto de instrucciones que guían al computador para realizar actividades o resolver problemas específicos.

Los temas clave que cubriremos incluyen:

  • Instrucciones: Acciones básicas que ejecuta el programa.
  • Estructuras de control: Formas de organizar el flujo del programa.
  • Elementos de un programa: Variables, constantes, bucles y acumuladores.

¿Qué es un Programa?

Un programa es un conjunto de instrucciones —órdenes dadas al computador— que guían al computador para realizar alguna actividad o resolver un problema. Todo programa debe especificar claramente:

  • Entrada: Los datos que ingresa el usuario o sistema.
  • Proceso: El algoritmo de resolución (conjunto de operaciones).
  • Salida: Los resultados que entrega el programa.
Flujo general: Entrada → Algoritmo de resolución → Salida

Tipos de Instrucciones

Una instrucción es una acción que el programa debe realizar. Puede ser una operación matemática, lectura de datos, escritura de resultados, asignación, bifurcación, etc.

Tipos principales de instrucciones:

Inicio/Fin

Marca el comienzo y fin del programa. El programa comienza con una instrucción de Inicio y finaliza con Fin.

Asignación

Asignan valores a variables. Ejemplo: de>A ← 12

Lectura

Permiten ingresar datos en el programa. Ejemplo: de>Leer B, C

Escritura

Muestran resultados del programa. Ejemplo: de>Imprimir resultado

Bifurcación

Toman decisiones basadas en condiciones. Interrumpen el orden secuencial.

Programas Lineales vs No Lineales

Programa Lineal Programa No Lineal
Acción 1 → Acción 2 → Acción 3 ... → Última acción Las acciones pueden saltar (bifurcaciones, ciclos)
Orden secuencial simple Orden secuencial con decisiones

Instrucciones de Asignación

La asignación permite guardar un valor en una variable. El operador de>← es fundamental en pseudocódigo.

Ejemplos de asignación:

A ← 12
B ← 23
C ← 12.5
suma ← A + B
multiplicación ← A * B
Importante: Antes de la ejecución, el valor de las variables es indeterminado. Si deseas un valor inicial, debes definirlo explícitamente: de>A ← 0, B ← 0, C ← 0

Operadores de asignación compuesta:

Operador Ejemplo Significado
+ op1 ← op1 + op2 Suma y asigna
- op1 ← op1 - op2 Resta y asigna
* op1 ← op1 * op2 Multiplica y asigna
/ op1 ← op1 / op2 Divide y asigna

Ejercicio de asignación:

¿Cuál será el valor de C después de estas instrucciones?

A ← 12
B ← A
C ← B

Respuesta: C = 12 (se asigna el valor de A a B, y luego el de B a C)

Lectura y Escritura de Datos

Lectura de Datos (Entrada)

La lectura permite introducir datos a la computadora desde teclado u otro dispositivo de entrada. Los datos se almacenan en las variables especificadas. 

Leer nomVar1, nomVar2, nomVarN
Leer B, C
Leer nombreEmp, horasTrab

Es recomendable acompañar la lectura con un mensaje solicitando los datos: 

Escribir "Ingrese el nombre del empleado:"
Leer nombreEmp
Escribir "Ingrese horas trabajadas:"
Leer horasTrab

Escritura de Datos (Salida)

La escritura permite mostrar datos en pantalla, impresora u otro dispositivo de salida. 

Imprimir nomVar1, nomVar2, nomVarN
Imprimir nombreEmp
Imprimir "NOMBRE: ", nombreEmp

Estructuras de Control

Las estructuras de control determinan el orden y la forma en que se ejecutan las instrucciones. Existen tres tipos principales:

Secuencial

Las instrucciones se ejecutan una tras otra, sin saltos ni decisiones.

Selectiva

Toma decisiones: ejecuta un bloque u otro según una condición.

Repetitiva

Repite un bloque de instrucciones un número de veces definido o hasta cumplir una condición.

Estructura Secuencial

En una estructura secuencial, las instrucciones se ejecutan una tras otra en el orden en que aparecen en el programa. No hay saltos ni decisiones.

Ejemplo: Suma y Cálculos Secuenciales

Escribir "Ingrese el primer número:"
Leer a
Escribir "Ingrese el segundo número:"
Leer b
resultado ← a + b
resultado ← resultado * 2
resultado ← resultado / a
Escribir "El resultado final es: ", resultado

Actividad propuesta

Diseña un algoritmo secuencial que convierta grados Celsius a Fahrenheit usando la fórmula: F = (C × 9/5) + 32

Estructura Selectiva (Condicional)

La estructura selectiva toma decisiones. Según una condición sea verdadera o falsa, ejecuta un bloque de instrucciones u otro.

a) Condicional Simple (SI)

Ejecuta un bloque solo si la condición es verdadera:

Si condición Entonces
    Acción 1
    Acción 2
FinSi

Ejemplo: Descuento por compra

Escribir "Ingrese el monto de compra:"
Leer compra
Si compra >= 1000 Entonces
    descuento ← compra * 0.10
    pago ← compra - descuento
    Escribir "Descuento aplicado: ", descuento
    Escribir "Total a pagar: ", pago
FinSi

b) Condicional Doble (SI / SINO)

Selecciona entre dos caminos posibles:

Si condición Entonces
    Acción 1
Sino
    Acción 2
FinSi

Ejemplo: Mayor de edad

Escribir "Ingrese su edad:"
Leer edad
Si edad >= 18 Entonces
    Escribir "Es mayor de edad"
Sino
    Escribir "Es menor de edad"
FinSi

c) Condicional Múltiple (Anidada)

Permite múltiples alternativas anidando estructuras condicionales:

Si condición1 Entonces
    Acción 1
Sino
    Si condición2 Entonces
        Acción 2
    Sino
        Si condición3 Entonces
            Acción 3
        Sino
            Acción 4
        FinSi
    FinSi
FinSi

Ejemplo: Clasificar un número

Escribir "Ingrese un número:"
Leer numero
Si numero > 0 Entonces
    Escribir "El número es positivo"
Sino
    Si numero < 0 Entonces
        Escribir "El número es negativo"
    Sino
        Escribir "El número es cero"
    FinSi
FinSi

Actividad propuesta

Diseña un algoritmo que lea tres notas de un estudiante y determine si está aprobado (promedio ≥ 60) o desaprobado usando estructura selectiva doble.

Estructura Repetitiva (Bucles)

La estructura repetitiva permite ejecutar un bloque de instrucciones múltiples veces, controladas por una condición o un contador. Esto se conoce también como ciclo o bucle.

Tipos principales:

1) Ciclo PARA (iteraciones conocidas)

Se utiliza cuando se conoce de antemano el número de repeticiones:

Para variable ← valorInicial Hasta valorFinal Hacer
    Acción 1
    Acción 2
FinPara

Ejemplo: Imprimir números del 1 al 10

Para i ← 1 Hasta 10 Hacer
    Escribir i
FinPara

Ejemplo: Sumar números del 1 al 100

suma ← 0
Para i ← 1 Hasta 100 Hacer
    suma ← suma + i
FinPara
Escribir "Suma de 1 a 100: ", suma

2) Ciclo MIENTRAS (iteraciones desconocidas)

Se utiliza cuando no se sabe cuántas veces se repetirá, depende de una condición:

Mientras condición Hacer
    Acción 1
    Acción 2
FinMientras

Ejemplo: Lectura con validación

Escribir "Ingrese un número positivo:"
Leer n
Mientras n <= 0 Hacer
    Escribir "Valor inválido. Ingrese un número > 0:"
    Leer n
FinMientras
Escribir "Valor aceptado: ", n

Actividad propuesta

Diseña un algoritmo que use un ciclo PARA para imprimir los números pares entre 1 y 50 y calcular su suma.

Contadores y Acumuladores

Contador

Un contador es una variable que se incrementa en una unidad constante cada vez que se ejecuta una instrucción dentro de un bucle. Se usa para contar eventos.

Ejemplo: Contar números impares

contadorImpares ← 0
Para i ← 1 Hasta 5 Hacer
    Leer numero
    Si numero mod 2 ≠ 0 Entonces
        contadorImpares ← contadorImpares + 1
    FinSi
FinPara
Escribir "Se ingresaron ", contadorImpares, " números impares"
Tres momentos del contador:
  1. Inicialización: contador ← 0
  2. Incremento: contador ← contador + 1
  3. Impresión/reporte: después del bucle

Acumulador

Un acumulador (o sumador) es una variable que acumula el resultado de operaciones variables dentro de un bucle. A diferencia del contador, el incremento es variable, no constante.

Ejemplo: Suma acumulada

Escribir "Ingrese un número positivo:"
Leer n
sumador ← 0
i ← 1
Mientras i <= n Hacer
    sumador ← sumador + i
    i ← i + 1
FinMientras
Escribir "La suma de 1 a ", n, " es ", sumador
Tres momentos del acumulador:
  1. Inicialización: acumulador ← 0
  2. Incremento variable: acumulador ← acumulador + valor
  3. Impresión/reporte: después del bucle

Elementos de un Programa

Elemento Descripción Ejemplo
Palabras Reservadas Palabras especiales del lenguaje Si, Sino, Para, Mientras, Leer, Escribir
Identificadores Nombres de variables, funciones, constantes edad, nombre, suma
Caracteres Especiales Símbolos de operación +, -, *, /, ←, =, >, <
Constantes Valores fijos que no cambian PI = 3.14159, MAXVAL = 100
Variables Espacios de memoria para almacenar datos edad, temperatura, resultado
Expresiones Combinación de operandos y operadores a + b, (x * 2) / 3
Instrucciones Órdenes que ejecuta el programa Leer x, Escribir y, z ← a + b

Partes constitutivas de un programa:

  • Declaración de variables: Definir las variables que se usarán.
  • Instrucciones: Las acciones que resuelven el problema.
  • Bucles: Estructuras para repetir código.
  • Estructuras de control: Controlan el flujo del programa.

Resumen de la Unidad III

Puntos clave:

  • Un programa es un conjunto de instrucciones organizadas en entrada → proceso → salida.
  • Las instrucciones son: inicio/fin, asignación, lectura, escritura y bifurcación.
  • Las estructuras de control son: secuencial, selectiva y repetitiva.
  • Los contadores cuentan eventos (incremento constante).
  • Los acumuladores suman valores (incremento variable).
  • El pseudocódigo es el primer paso para diseñar un algoritmo antes de programar.
